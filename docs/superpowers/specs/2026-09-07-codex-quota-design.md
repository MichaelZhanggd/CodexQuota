# Codex Quota

制作 macOS 原生额度组件，绑定当前 Codex 桌面应用；支持吸附、跟随移动、跟随显隐、独立始终置顶和登录启动。

## 用户体验

- SwiftUI 圆角中性灰卡片，适配系统深浅色，展开尺寸约 300 × 330；可折叠为迷你条。
- 显示服务端提供的额度窗口、剩余百分比、重置倒计时和刷新时间。无数据显示未知，失败保留最后一次数据并标记过期，不伪造额度恢复。
- 菜单栏入口始终可用，支持唤回、切换模式、刷新和退出。
- 位置独立于显示模式：靠近 Codex 四边松手吸附，拖离解除；绑定明确窗口，多窗口不随意切换。默认尝试右侧，屏幕空间不足改用可用边缘或贴内侧。
- 跟随模式：只有绑定窗口在当前桌面可见、未最小化、Codex 在前台时显示。始终置顶：Codex 隐藏或退出也显示。普通：不置顶。
- 登录启动由设置开关控制，默认关闭。使用 SMAppService，无后台周期性 AI 任务。

## 架构与边界

QuotaCore：可测试的额度 JSON 解析、时间和百分比计算、吸附几何与显示策略。

QuotaClient：启动随本机 Codex 安装的 app-server，通过 stdio JSON-RPC initialize → initialized → account/rateLimits/read。保持一个子进程，默认 60 秒只读查询，支持 30/120/300 秒；处理额度通知、超时、进程退出、断网、睡眠唤醒；退出时清理子进程。不创建模型请求，不存储认证信息。

WindowTracker：通过公开 CGWindowList 获取 com.openai.codex 的窗口 ID、坐标和可见性；AX 权限可用时读取窗口信息辅助识别。仅依赖公开 API，不读取聊天内容。拖动时 20Hz 跟随，空闲降低刷新成本；坐标统一到 AppKit，兼容负坐标副屏。不强制申请录屏权限。

AppKit NSPanel 承载 SwiftUI，非激活面板避免抢焦点。UserDefaults 保存模式、窗口位置、折叠、吸附和刷新间隔；窗口 ID 只在当前进程有效，重启重新绑定。

## 验证

swift test 覆盖多额度桶优先级、未知窗口、百分比边界、重置时间、吸附四边、负坐标屏幕、无空间回退、显隐模式。

本机真实 app-server 只读集成验证；打包签名后启动应用；通过自身视图离屏渲染截图检查深浅色与迷你条。窗口拖动、最小化、隐藏恢复、模式切换以及登录启动在系统授权允许的范围内验证，未实测项如实记录。
