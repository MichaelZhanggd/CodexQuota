# Codex Quota

一个 macOS 原生 Codex 额度组件。安装位置：`~/Applications/Codex Quota.app`。

## 使用

1. 打开 **Codex Quota.app**，确保 Codex 桌面应用已登录。
2. 菜单栏中的终端图标显示短周期剩余百分比；点击展开卡片，右键可切换显示模式。
3. 拖动卡片左上角 **Codex 标题区域**，靠近 Codex 窗口四边后松手吸附；拖离解除。迷你条从左侧终端图标拖动；空心图钉点击吸附当前 Codex，实心图钉点击解除。
4. 右上角「−」折叠；迷你条右侧按钮展开；滑杆图标打开设置。
5. 设置中的「登录后自动启动」可开启开机登录启动；默认关闭。系统要求确认时会打开登录项设置。

## 显示与吸附

| 模式 | 行为 |
|---|---|
| 跟随 Codex（默认） | 绑定窗口在当前桌面可见且 Codex 在前台时显示；窗口隐藏、最小化或切换其他应用时收起；恢复后显示。 |
| 始终置顶 | Codex 隐藏、最小化或退出后仍独立显示。 |
| 普通窗口 | 不置顶，允许其他窗口覆盖。 |

位置吸附和显示模式独立。默认吸附 Codex 右侧，屏幕外侧没有空间时贴到窗口内侧。支持左、右、上、下吸附，保留沿边偏移，移动或调整 Codex 窗口时同步更新。拖动中约每 50ms 跟踪，空闲时降低频率。

多窗口时绑定具体窗口 ID；关闭绑定窗口后，不自动跳到另一个任务窗口。需要时从设置点击「吸附当前 Codex」。重启 Codex 后重新识别窗口。

从菜单栏主动唤出时，会临时显示约 12 秒，便于在 Codex 不在前台时操作设置。「收起到菜单栏」会保持收起，直到主动唤回。界面记住位置、吸附、折叠、显示模式、主题和刷新间隔。

## 额度数据

- 通过本机 Codex 自带的 `app-server` 使用 `account/rateLimits/read` 读取当前登录账号的真实额度。
- 优先使用 `rateLimitsByLimitId`，支持多个额度桶；兼容旧版 `rateLimits`。
- 展开卡片会显示当前账号可用的额度重置卡数量；服务端未返回时显示“重置卡 —”，不误报为 0 张。
- 默认每 60 秒查询，可选 30 秒、2 分钟或 5 分钟，并接收 app-server 的额度更新通知。属于定时近实时更新，不承诺服务端秒级推送。
- 查询不创建 AI 对话，不调用模型。应用不读取、复制或保存认证令牌，不需要 API Key。
- 失败保留上次数据并标记过期，超时后退避重连；不把未知值当作 0%，不在重置时自行假定恢复到 100%。
- 窗口跟踪只读系统窗口 ID、位置和可见性，不读取聊天内容；本机已验证无需辅助功能或录屏权限。

## 构建与验证

需要 Xcode Command Line Tools / Swift 5.9+、macOS 13+。当前成品针对本机 Apple Silicon 构建，约 1.3 MB，无第三方依赖。

```sh
cd ~/CodexQuota
swift test
./scripts/build.sh
.build/release/CodexQuota --check-quota
.build/release/CodexQuota --check-windows
.build/release/CodexQuota --render-previews "$PWD/dist/previews"
```

`dist/Codex Quota.app` 是本地签名的成品。手动安装可拖到用户「应用程序」文件夹。不要移动已启用登录启动的应用；需要移动时先关闭登录启动，移动后重新开启。

实际显隐检查（会短暂隐藏／恢复 Codex，并重启额度组件；结束恢复偏好与前台状态）：

```sh
xcrun swift scripts/check-window-lifecycle.swift
```

已验证：额度读取、13 项自动化测试、发布构建与签名、深浅色与迷你条的实际视图渲染、真实 Codex 隐藏／恢复下两种置顶模式的区别。

尚未在真实会话中自动验证：鼠标拖拽、最小化动画、跨 Space/全屏切换及重新登录启动。吸附几何、副屏负坐标和显示策略已有自动化覆盖；登录启动使用系统 SMAppService 接口。

预览图使用标明在代码中的固定样例数值，仅供界面检查；正常运行始终读取真实数据。

## 隐私

应用只通过本机 Codex 进程读取额度，不读取或保存认证令牌、API Key、账号资料及聊天内容，也不向第三方服务发送数据。窗口吸附只读取 Codex 窗口的位置和可见状态。

## 卸载

先在设置中关闭「登录后自动启动」，退出应用，然后删除 `~/Applications/Codex Quota.app`。源码位于 `~/CodexQuota`，可按需保留。
